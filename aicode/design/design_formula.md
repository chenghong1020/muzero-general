# MuZero 算法中的关键公式

## 回放缓冲区 (Replay Buffer) 相关公式

### 1. 优先经验回放 (Prioritized Experience Replay)

#### 优先级计算
优先级基于预测值与目标值之间的差异：
p(i) = |V(s_i) - V_target(s_i)|^α

其中：
- p(i) 是样本i的优先级
- V(s_i) 是网络预测的状态s_i的价值
- V_target(s_i) 是计算得到的目标价值
- α 是优先级指数，控制优先级的程度（α=0时退化为均匀采样）

#### 重要性采样权重
为了纠正优先采样引入的偏差，使用重要性采样权重：
w(i) = 1/(N·P(i))

其中：
- w(i) 是样本i的重要性权重
- N 是总样本数
- P(i) 是样本i被采样的概率

### 2. 时序差分 (Temporal Difference) 学习目标

#### n步时序差分目标值
V_target(s_t) = γ^n · V(s_{t+n}) + ∑_{i=0}^{n-1} γ^i · r_{t+i+1}

其中：
- V_target(s_t) 是状态s_t的目标价值
- V(s_{t+n}) 是n步后状态的估计价值
- r_{t+i+1} 是在时间步t+i+1获得的奖励
- γ 是折扣因子
- n 是时序差分步数

#### 超出游戏长度的处理
当n步后超出游戏长度时：
V_target(s_t) = ∑_{i=0}^{T-t-1} γ^i · r_{t+i+1}

其中T是游戏总步数。

### 3. 策略目标

策略目标基于MCTS访问计数：
π_target(a|s) = N(s,a) / ∑_b N(s,b)

其中：
- π_target(a|s) 是在状态s下选择动作a的目标策略
- N(s,a) 是MCTS搜索中状态s下动作a的访问次数
- ∑_b N(s,b) 是所有动作的访问次数总和

### 4. 梯度缩放

为了平衡不同展开步骤的贡献，使用梯度缩放因子：
scale = 1/K

其中K是展开步数。
